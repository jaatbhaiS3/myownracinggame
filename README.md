# 🏎️ Ferrari Racing Game

A high-speed racing game built with HTML5 Canvas and JavaScript!

## 🎮 Play Now
**[🚀 PLAY THE GAME HERE](https://jaatbhaiS3.github.io/myownracinggame/)**

## Features

✨ **Awesome Gameplay:**
- Control a legendary red Ferrari
- Dodge incoming traffic
- Collect gold coins for points
- Nitro boost with Space bar
- Progressive difficulty

🏆 **Scoring System:**
- Avoid cars: -100 points per crash
- Successfully dodge: +10 points
- Collect coins: +50 points
- Game ends after 5 crashes

⚙️ **Controls:**
- **← →** or **A/D** - Move left/right
- **Space** - Activate Nitro Boost
- **Arrow Keys** - Full directional control

## 🎯 Game Mechanics

1. **Your Car:** A sleek Ferrari with gold stripe and prancing horse logo
2. **Obstacles:** Red enemy cars coming down the road
3. **Power-ups:** Gold coins for bonus points
4. **Difficulty:** Gets progressively harder as you survive

## 📊 Tips to Win

- Stay in your lane and avoid center traffic
- Use the sides of the road strategically
- Save boost for critical moments
- Collect coins whenever possible
- Beat the high score: 5000+ points = Legend! 🏆

## 🛠️ Technologies Used

- **HTML5 Canvas** - Game rendering
- **Vanilla JavaScript** - Game logic
- **CSS3** - Styling and animations

## 📝 How to Play Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/jaatbhaiS3/myownracinggame.git
   ```

2. Open `index.html` in your browser

3. Start racing! 🏁

## 🚀 Deploy Your Own

This game is hosted on GitHub Pages. To deploy:

1. Go to Settings → Pages
2. Select "Deploy from a branch"
3. Choose `main` branch
4. Save and wait 2-3 minutes for deployment

Works on:

- ✅ Firefox
- ✅ Safari
- ✅ Edge

## 🎨 Customization

Want to modify the game? Edit `index.html`:
- Change colors in the `drawPlayer()` function
- Adjust difficulty in `enemySpawnRate`
- Modify physics in the `update()` function
- Add new power-ups or obstacles
